# ChatNU Android

ChatNU is an open-source, decentralized messenger for Android. The client is being rebuilt around a local-first identity, end-to-end encrypted message envelopes, user-selectable relay nodes, and an intentionally polished mobile experience.

## Current branch scope

`feature/chatnu-ios-redesign` replaces the original flat file dump with a real Android project and a production-oriented UI foundation:

- Kotlin + Jetpack Compose
- edge-to-edge dark glass design system
- animated onboarding and decentralized mesh illustration
- chat list, conversation, relay node, and settings flows
- in-memory demo repository for frontend iteration
- backend-facing API and realtime contracts
- server URLs supplied through `BuildConfig`, not hardcoded throughout the UI

## Run

Open the project with a current Android Studio version and use JDK 17.

The repository intentionally declares Gradle 8.13. If `gradle/wrapper/gradle-wrapper.jar` is missing after checking out this branch, run:

```bash
gradle wrapper --gradle-version 8.13
./gradlew assembleDebug
```

The wrapper JAR is binary and is not generated by the GitHub connector used for the initial reconstruction.

## Backend boundary

The client currently uses demo data. Networking contracts live under:

```text
app/src/main/java/com/devnu/chatnu/core/network
```

Default endpoints:

```text
REST:      https://api.devnu.ir
WebSocket: wss://api.devnu.ir/realtime
```

Override them through build configuration when the backend is ready.

## Security status

The screens and envelope models are not a completed cryptographic implementation. Do not claim production E2EE until the key lifecycle, audited ratchet implementation, encrypted database, attachment encryption, device verification, and recovery design are completed and reviewed.
